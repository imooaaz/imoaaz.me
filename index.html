A security engineer with a developer's background

I'm a cybersecurity engineer, penetration tester, and co-founder of Raqyan, where I lead software product delivery, product security, and DevOps & DevSecOps. I came to security from software development, and it still shapes how I work: I read code, not just responses. An exploit only makes sense once you understand what the developer intended.

My experience spans penetration testing, vulnerability assessment, and bug bounty research, both inside product teams and as a consultant working directly with clients. One of my disclosures became CVE-2024-36436.

Current focus: offensive security, web and mobile application security, secure software delivery, and the security of AI-powered products.

What I do

  1. Web & Mobile Penetration Testing

    Scoped assessments of web applications, APIs, and Android apps. Every finding is manually verified and documented with clear reproduction steps and remediation guidance.

    Web · Mobile · API · Reporting

  2. Product Security & DevSecOps

    Security built into how software ships: automated checks in CI/CD, secure defaults, and release processes where speed and security stop competing.

    CI/CD · Automation · Secure Delivery

  3. Application Security

    Security embedded in product teams: secure code review, threat-informed testing across the SDLC, and working with developers rather than around them.

    AppSec · Secure SDLC · Code Review

  4. Security Research & Bug Bounty

    Finding vulnerabilities in live systems and taking them through coordinated disclosure, including CVE-2024-36436.

    Recon · Vulnerability Research · Disclosure

  5. AI Security

    Assessing AI-powered features the way attackers approach them: prompt injection, weak authentication around model endpoints, and data exposure across a new attack surface.

    LLM Applications · Authentication · Abuse Cases
